关于我

👋 你好，我是 GG

“我是一只咸鱼，不想承认，也不能否认。”

🐟 关于 “GG”

这个名字没有任何深奥的含义，纯粹是键盘上偶然敲击出的火花。
最近有人叫我 GG Bond，我也没否认——毕竟，本人确实也到了那种“起飞”的趋势。

💻 技术与生活

搭建这个网站，是我在喧嚣世界里留给自己的一片自留地：

  • 技术笔记：记录我在运维路上的坑坑洼洼。从 Linux 到云原生，希望这些经验能偶尔帮到路过的你。
  • 胡思乱想：通过日记或写作，强迫大脑从碎片化的生活中抽离，去思考，去复盘。
  • 快门瞬间：我很喜欢拍照。用实习第一份工资买了一台老旧的 Sony a6400，挂着一颗 50mm 的定焦头。虽然囊中羞涩，但镜头里的世界依然很美，我会在这里分享我的摄影作品。

🌊 逆流而上的咸鱼

“我没有任何天分，我却有梦的天真。”

我的教育历程并不算出众，但我庆幸当初没有选择那条唯一的“文化课”道路：

  • 职中时期：梦想萌芽的地方。职一开始进入训练队，主攻 Linux 与 Windows 服务器系统。毕业前拿下国赛二等奖，这枚奖牌定格了我的职业方向。
  • 大专时期：我加入了记者团新媒体部，运营公众号是我最快乐的时光。为了热爱，我甚至在专插本时跨专业备考大学语文，虽然最后失败了，但那次转身让我学会了听从内心。
  • 现状：目前在一家小私企做运维。虽然生活只是“有一点起色，但不多”，但我从未停止进步。

🛠️ 技能清单

  • Red Hat Certified Engineer (RHCE)
  • Certified Kubernetes Administrator (CKA)

🌙 结语

“我不愿一生，晒太阳吹风，咸鱼也要有梦。”

这些词出自五月天的《咸鱼》（《憨人》国语版），它陪伴我走过许多时刻，让我始终保持那份纯真。

在这里，我只会做我自己。我们通过网线在发光的屏幕前相见，思路通过跳跃的字节发生碰撞——这，就是我想做的事情。
